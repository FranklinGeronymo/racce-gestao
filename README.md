# Racce · Gestão da loja

Sistema de gestão da Racce (moda fitness unissex, Fortaleza · CE): vendas com catálogo, recibo de venda, estoque com fotos, despesas, metas por mês, resultado do mês, usuários com acesso por função e histórico de alterações das vendas.

## Como usar

Abra o endereço do GitHub Pages deste repositório no Google Chrome ou no Microsoft Edge.

## Onde ficam os dados

O sistema é um único arquivo (`index.html`) e não envia nada para o GitHub nem para outro servidor. As vendas, o estoque, as fotos e os usuários ficam salvos **no navegador de quem usa**:

- cada computador e cada navegador têm os próprios dados;
- quem abrir o link em outro aparelho vê o sistema vazio, sem os dados da loja;
- os dados da versão online não se misturam com os do arquivo aberto direto do computador. Para levar os dados de um para o outro, use **Ajustes > Baixar backup** e **Ajustes > Restaurar backup**;
- faça backup toda semana e guarde o arquivo `.json` fora do computador (por exemplo, no OneDrive).

## Atualizar

Substitua o `index.html` pela versão nova. Os dados continuam no navegador.
